# Commit et push GitHub

À exécuter dans un terminal (PowerShell ou CMD) à la racine du projet :

```bash
git add -A
git status
git commit -m "Modals site/observation: 3 photos max, design teal/sections, champ date mobile, date site modifiable, espacement boutons GPS"
git push
```

Si tu préfères un message plus court :

```bash
git add -A
git commit -m "Améliorations modales + build AAB"
git push
```
